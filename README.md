# Alternativa — Living Solutions

Landing page corporativa one-page para Alternativa.

## Ejecutar en local

Abre `index.html` directamente o sirve la carpeta con `python -m http.server 8080`.

## Identidad

Paleta: naranja `#FF7A00`, azul profundo `#0B2D94`, gris azulado `#6B7C93`, gris claro `#E8ECEF`.
